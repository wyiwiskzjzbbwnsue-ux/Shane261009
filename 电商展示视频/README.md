# 电商展示视频

Shane 的电商产品展示视频项目存档。给后来接手的 AI 看：**先读各项目的 README，再动手**，里面的规则是用户一次次反馈定下来的，不要凭感觉推翻。

## 项目

- [毛毛虫儿童房衣柜拉手](./毛毛虫儿童房衣柜拉手/README.md)：15 秒竖版展示视频，2026-10-26 定稿 v8，用户评价“基本符合要求”。含最终构建脚本 `build_v8.py`、文案素材生成脚本 `make_assets_v8.py`、配音文案 `narration_v8.txt`。
- [古铜色水滴拉手](./古铜色水滴拉手/README.md)：30 秒展示视频，v2 已交付并存档到 Google Drive；用户不满意、待用 3 张新图重做（进行中，见该项目 README）。

## 通用铁律（两个项目都适用）

1. **产品不能变形是最高优先级。** 不用 AI 生成视频（逐帧重绘必变形），不用 AI 生成场景图（用户说“很假”）。产品只用原图静态展示 + 缓慢运镜。
2. **用户照片先做 EXIF 方向校正再处理。** 有的照片存储像素方向与真实构图不一致（见毛毛虫项目：EXIF orientation 8，真实是竖构图）。
3. **运镜要慢。** 推拉幅度约 3%/镜、平移约 360px/2.5s；用户两次嫌“太快”。
4. **文案写给客户看，讲好处不讲参数。** 不写“陶瓷”“安装”这种裸关键词；上面贴纸是好处短语、下面文案是展开的好处句，上下呼应。
5. **用户说“算了”就是彻底放弃**，不要在同一口气里抢救任务；把断点和一句话恢复方式写清楚即可。

## 为什么成品视频和原图不在仓库里

当前 GitHub 连接器只支持推送 UTF-8 文本文件，二进制（mp4、jpg）无法通过它同步。所以仓库里只有文档和脚本；成品视频、原图、音频素材的位置写在各项目 README 里（本地工作目录和 Google Drive），需要时从那里取。
