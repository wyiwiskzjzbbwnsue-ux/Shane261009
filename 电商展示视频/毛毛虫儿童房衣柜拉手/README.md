# 毛毛虫儿童房衣柜拉手 · 15 秒竖版展示视频

- 产品：陶瓷毛毛虫造型儿童房衣柜拉手（粉 / 蓝 / 薄荷绿 / 黄 / 白五色）。
- 用户给的卖点：陶瓷材质、哑光质感、安装方便。
- 成片：`毛毛虫儿童房衣柜拉手_15秒展示_v8.mp4`（720×1280，30fps，15.1 秒），2026-10-26 定稿，用户评价“基本符合要求”。
- 构建脚本：`build_v8.py`（ffmpeg 分镜 + xfade 转场 + 配音混音）；文案贴纸生成：`make_assets_v8.py`（PIL）；配音文案：`narration_v8.txt`。

## 最高优先级规则（不要违反）

1. **只用原图，产品像素一帧不动。** 不用 AI 生成视频、不用 AI 场景卡、不用 AI 抠图上门效果——用户在 v5 明确否决：“这些图片生成就很假了”。
2. **EXIF 校正先行。** 4 张原图存储为 6960×4640 横向像素、EXIF orientation 8，真实构图是竖版 4640×6960。必须先 `exif_transpose` 再处理，前两版就是因为按横图处理被用户指出。
3. **运镜慢。** 推拉幅度 3%/镜（zoompan 步进 0.0004×帧），平移 360px/2.5s（窗口在 1440 宽的预缩放图上从 x=180 移到 540，或反向）。用户两次嫌快，v7 从 5% 降到 3%、平移减半后才通过。
4. **文案讲客户好处，不讲裸参数。** v7 的贴纸只写“陶瓷”“安装”两个字被用户否决。改成：上面贴纸 = 好处短语，下面文案 = 展开的好处句，上下呼应（见下表）。
5. **贴纸配色取自产品本身的马卡龙色系 + 深灰字**，看得清但不突兀，能融进画面。不要用高饱和撞色（v7 之前的大红/亮橙贴纸显得突兀）。
